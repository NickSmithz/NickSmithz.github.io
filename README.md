# FORM 08 — домашняя программа тренировок · версия 2.0

Готовый адаптивный одностраничный сайт без сборщиков и внешних библиотек.

## Запуск
1. Скачайте архив ветки.
2. Распакуйте файлы.
3. Откройте `index.html` в браузере.

Изображения расположены в папке `assets/` и работают офлайн.
Карточки упражнений переворачиваются по нажатию. Для каждого упражнения приведены работающие мышцы, техника и частая ошибка. Доступны фильтры, поиск, карта приблизительного распределения подходов и отслеживание выполнения по восьми неделям (localStorage).

## Публикация
Готовый статический сайт можно разместить на GitHub Pages, Netlify или Cloudflare Pages без установки зависимостей.

## Важно
Изображения упражнений сгенерированы ИИ и носят иллюстративный характер. При расхождении иллюстраций и текстовой техники приоритет у текста. Имитация академической гребли не является полноценной заменой тренировкам на гребном эргометре или воде.

Программа рассчитана на 3 силовые тренировки в неделю: понедельник / среда / пятница; длинная трубчатая резина без ручек и упражнения с собственным весом.
